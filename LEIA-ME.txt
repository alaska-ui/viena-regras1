# VIENA — ATUALIZAÇÃO

Esta pasta contém os arquivos que devem substituir os arquivos atuais do site.

## Arquivos

- `index.html`
- `style.css`
- `app.js`
- `admin/config.yml`

## IMPORTANTE

NÃO substitua:

- `content/site.json`
- `content/rules.json`
- `uploads/`

Esses arquivos já possuem os dados e imagens cadastrados.

## O que foi corrigido

### 1. Regra nova do Admin

O `app.js` agora busca `site.json` e `rules.json` diretamente do GitHub RAW primeiro.

Isso evita que o GitHub Pages continue entregando uma versão antiga do JSON depois que você salva uma regra nova pelo Admin.

### 2. Admin mais simples

O texto da regra agora usa campo de texto simples em vez do editor Markdown avançado.

Para criar uma regra:

1. Abra `Regras`.
2. Abra `Categorias e Regras`.
3. Abra a categoria desejada.
4. Abra `📌 Regras desta categoria`.
5. Clique para adicionar uma regra.
6. Preencha:
   - Código
   - Título
   - Texto
   - Tag
   - Imagem opcional
7. Salve.

### 3. Imagem da capa

A imagem escolhida em `Imagem de fundo da capa` continua sendo usada como imagem de fundo de toda a área inicial.

### 4. Cursor

O cursor continua usando a imagem escolhida no Admin e o rastro continua funcionando em todas as áreas da página.

### 5. Navegação

O cursor e os cliques funcionam no menu, cards, botões, pesquisa, resultados e índice das regras.

## Não apague os dados atuais

O objetivo desta atualização é trocar apenas a estrutura do site e do painel.

As regras e imagens existentes devem permanecer nos arquivos atuais.
