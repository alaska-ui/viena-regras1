# VIENA — Atualização do Código da Rua

Substitua os arquivos correspondentes:

- `index.html` → raiz do projeto
- `style.css` → raiz do projeto
- `app.js` → raiz do projeto
- `config.yml` → raiz do projeto

## O que foi adicionado

1. Texto das regras com Markdown.
2. Negrito com `**texto**`.
3. Itálico com `*texto*`.
4. Títulos com `#`, `##`, `###`.
5. Listas com `-`.
6. Listas numeradas com `1.`.
7. Caixas especiais:
   - `> ⚠️ **ATENÇÃO**`
   - `> ℹ️ **OBSERVAÇÃO**`
   - `> ❌ **PROIBIDO**`
   - `> ✅ **PERMITIDO**`
8. Botões `ANTERIOR` e `PRÓXIMA` no final de cada categoria.
9. Botão `VOLTAR AO MAPA` entre eles.
10. Letras/símbolos vermelhos caindo pela tela.
11. Cursor com a logo configurada no Admin.
12. Rastro do cursor preservado.
13. Imagem da categoria NÃO aparece no Mapa da Rua.
14. Campos do Admin configurados como opcionais.
15. Se o ID da categoria ficar vazio, o site cria um ID automaticamente.

## Exemplo para uma regra

```md
# ANTI RP

Ter condutas que vão contra o bom andamento do RP.

> ⚠️ **ATENÇÃO**
>
> É proibido qualquer ato de corrupção na Polícia ou Hospital.

> ℹ️ **OBSERVAÇÃO**
>
> Organizações previamente aprovadas pela Administração poderão possuir RPs específicos.

- Respeite o contexto.
- Preserve o RP.
- Não abuse de permissões.
```

Não precisa mexer no JavaScript para criar novas regras. Depois de publicar pelo Admin, o site lê o `content/rules.json` automaticamente.
